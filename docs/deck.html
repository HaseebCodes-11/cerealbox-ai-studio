Typed schema

Every model call returns JSON that matches a Zod schema (Claude structured outputs). Malformed output never reaches a person.

Deterministic guardrails

Claims, pressure language, placeholders, PII, banned words, limits, invented statistics. Block / warn / info.

Human gate

Auto · one-click approve · human decision. The pipeline stops at a pending gate. Everything is in the audit log with cost.

Principles

How I decided what the machine does and what people do

  • AI touches text and suggestions: ideas, copy, specs, scripts, captions, narratives, drafts.
  • Code touches numbers and structure: limits, contrast, pacing, every metric, every rule that moves budget.
  • Humans touch brand, money and people: shortlist, approve, pause, publish, send.
  • Deterministic mock first, real model second: offline, reproducible, free; switching to Claude is one environment variable.
  • Autonomy is earned per client: assist → copilot → autopilot, inside hard caps.

Quality controls

How bad outputs are stopped before a human sees them

  • Structured outputs + schema re-validation on every call; refusals and truncation raise typed errors.
  • Allowed-facts rule: the only numbers accepted are the brief's proof points, tiers, match line and statutory facts (Gift Aid 25%).
  • Guardrails for the Fundraising Regulator code: no guarantees, pressure or guilt framing, US tax framing, superlatives.
  • Visual and structural QA on creatives and pages; number verification on client reports and replies.
  • Evals in CI: red team, scorecards, agent scenario recall, LLM-as-judge. A regression does not merge.
Maintenance · scale · cost

Built to be kept, not demoed once

Maintenance

Every AI step is a named task with schema, prompt, mock and effort. Provider and model are environment variables. Telemetry tables record tokens, cost, latency, schema validity and gate rejection rates.

Scale

Everything keyed by client behind Row-Level Security; the brief carries voice, palette and compliance notes, so one pipeline serves 30 charities. Thresholds are per-client data, not code.

Cost

About $0.16 per campaign package and $0.02 per daily agent run at Opus list prices. Model cost is not the constraint; vendor media (£25–40 synthetic UGC vs £350 creator) and people time are.
